# Historical Qwen scripts — reference only

These scripts preserve the original experiment structure while replacing machine-specific paths and nonessential private identifiers with placeholders. Original and published SHA-256 values are recorded separately in [the provenance index](../../evidence/provenance.json).

The experimental runners still depend on external `res1_instance` and `resource_profile` modules, which are **not** bundled. Do not present them as ready-to-run standalone software or substitute unreviewed external source code. The archived result aggregation is independently available in [scripts/summarize_qwen.py](../../scripts/summarize_qwen.py).
